# mcp-websocket-proxy (npm distribution)

Ultra-fast, low-RAM Model Context Protocol (MCP) stdio-to-WebSocket proxy and router.

## Quick Start

Run directly without installing:

```bash
npx mcp-websocket-proxy serve -- npx -y @modelcontextprotocol/server-filesystem ./workspace
```

Or install globally:

```bash
npm install -g mcp-websocket-proxy
mcp-websocket-proxy --help
```

See the main [documentation repository](https://github.com/furymob-git/mcp-websocket-proxy) for full usage instructions and multi-server routing.
