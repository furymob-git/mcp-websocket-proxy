# Security Policy

## Supported Versions

Only the latest release of `mcp-websocket-proxy` is actively supported with security updates.

| Version | Supported          |
| :---    | :---               |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within `mcp-websocket-proxy`, please report it responsibly:

1. **Do not open a public GitHub issue.**
2. Send an email to the maintainers or report via [GitHub Private Vulnerability Reporting](https://github.com/eliot/mcp-websocket-proxy/security/advisories/new).
3. Include detailed steps to reproduce the vulnerability, including any relevant code samples, network payloads, or configurations.

You will receive an acknowledgment within 48 hours, followed by updates on the timeline for a fix and release.
